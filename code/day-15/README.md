# Day 15 Lab: Partition Table Analyzer (MBR vs GPT)

## For Beginners to Python

Welcome to Day 15! In this lab, we explore why older computers cannot use hard drives larger than 2.2 Terabytes, and why modern systems require GPT.

### What Does This Script Do?
It calculates the exact mathematical limits of 32-bit MBR partition tables versus 64-bit GPT tables.

### How to Run
```bash
python partition_parser.py
```
